# 注释规范

- [ ] 类、类变量、方法必须用 Javadoc 格式 `/** */`，不用 `// xxx`
- [ ] 接口和抽象方法必须有 Javadoc，含方法说明、参数描述、返回值说明、可能的异常
- [ ] 每个类必须有作者（@author）和日期信息
- [ ] 方法内单行注释用 `//` 置于代码上方并对齐，多行注释用 `/* */`
- [ ] 枚举类型的所有字段必须有 Javadoc 注释
- [ ] 注释中中英文混用时，专有名词和关键字保持英文
- [ ] 代码逻辑变更时同步更新注释，尤其是参数、返回值、异常、核心逻辑的变更
- [ ] 注释掉的代码需加说明理由，否则直接删除（git 有历史）
- [ ] TODO 和 FIXME 标签必须包含作者和时间，定期清理
