# 格式规范

- [ ] 大括号规则：空代码块 `{}`，非空时左括号前不换行、后换行，右括号前换行、后换行（除非后面跟 else 或逗号）
- [ ] 括号 `(` 后和 `)` 前无空格
- [ ] `if`/`for`/`while`/`switch` 与括号之间一个空格
- [ ] 运算符（`=`、`&&`、`+`、`-`、三元运算符）两侧各一个空格
- [ ] 缩进用 4 个空格，禁止 tab
- [ ] 行宽不超过 120 字符；超长时第二行缩进 4 格，`.` 和运算符随下一行，逗号后换行，括号前不换行
- [ ] 多参数方法逗号后一个空格：`f("a", "b", "c")`
- [ ] 文件编码 UTF-8，换行符 Unix 格式（LF）
- [ ] 不用多余空格对齐变量声明
- [ ] 相同逻辑或语义的代码段之间用一个空行分隔，不用多个空行
