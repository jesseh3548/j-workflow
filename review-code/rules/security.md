# 安全

- [ ] 用户相关的页面/接口是否有鉴权？
- [ ] 用户敏感数据是否脱敏展示？（手机号 `158****9119`）
- [ ] SQL 参数是否使用 `#{}` 参数化查询，防止 SQL 注入？
- [ ] 用户输入参数是否做了校验？（防止 OOM、慢查询、任意重定向、SQL 注入、反序列化注入、ReDoS）
- [ ] 输出到 HTML 的用户数据是否转义，防止 XSS？
- [ ] 表单/AJAX 提交是否有 CSRF 防护？
- [ ] 短信/邮件/支付等资源操作是否有频率/次数限制和验证码？
- [ ] 用户生成内容（发帖、评论、即时消息）是否有敏感词过滤和风控策略？
